One short rant, at most 400 characters: the funniest rant about a small everyday annoyance — a toaster with the confidence of a cat.

The rant it writes:

> The toaster launched my bread onto the floor, butter-side down, with the confidence of a cat knocking a glass off a table.

## Run it

```sh
node main.ts
```

It writes exactly that one rant (122 characters, no trailing newline) to `ENTRY_OUTPUT`, or `/output/entry.txt` when unset.
